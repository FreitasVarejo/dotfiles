# Esta máquina: pi01

Descrição da máquina: `hosts/pi01.md` no vault (`~/ObsidianVault`).

- **Um subagente com build pesado por vez.** Não dispare em paralelo dois subagentes que rodam build .NET, testes de mutação ou E2E: aqui o paralelo não ganha tempo e deixa a produção lenta. Subagente que só lê, pesquisa ou edita pode rodar junto.
- **Sem .NET SDK, sem CUDA e sem venv de Python.** Build e teste de .NET e Python rodam em container (`docker compose run`).
